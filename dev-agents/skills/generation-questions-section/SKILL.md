# Proposito

Durante la iteración si necestias que el usuario responda a alguna pregunta de cualquier índole, generarás un `questions.txt` o actualizas si existe con las preguntas que necesitas que responda el usuario.

# Cuando usar

- Cuando necesitas que el usuario responda preguntas en vcaulquier momento de la iteración
- Si en el fichero hay preguntas sin responder parar y avisar al usuario
- Tambien pudes proponen en el ese fichero opciones
