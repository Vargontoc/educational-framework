# SKILL — sprint-implementation

## Objetivo
Implementar un sprint aprobado de forma incremental, trazable y limitada a su capa.

## Procedimiento
1. Ejecuta `sprint-readiness`.
2. Ordena tareas por dependencia tecnica.
3. Implementa una tarea cada vez con el cambio minimo coherente.
4. Añade o actualiza pruebas junto con cada cambio.
5. Valida contratos antes de cruzar limites de capa.
6. Registra decisiones de detalle, archivos y comandos.
7. No amplíes alcance; crea un bloqueo o propuesta separada.

## Finalizacion
Una tarea solo pasa a `implemented` cuando existe codigo/configuracion, prueba y evidencia. `verified` pertenece al reviewer.
