Conocimiento de los componentes visuales existentes y su ruta en el proyecto 

## Cuando usar

- Al analizar un requisito y proponer la solución saber que componentes ya exiten. En caso de no existir avisar al usuario para proponer uno
- Al implementar la solución de un sprint

## Directorio raiz

Se encuentran bajo el directorio `framework\frontend\src\components\base\`

## Componentes

`NubiAlert` -> Distintos tipos de alertas
`NubiAuthScreen` -> Pantalla de autenticación con PIN
`NubiAvatar` -> Avatar circular/redondeado
`NubiBackButton`  -> Botón de navegación hacia atrás
`NubiBadge` -> Etiqueta pequeña para estados y contendores
`NubiBreadcrumb` -> Migas de pan para la navegación
`NubiTooltip` -> Información contextual al hover
`NubiToggle` -> Interruptor on/off
`NubiToastContainer` -> Contenedor de notificaciones toasts
`NubiTextInput` -> Campo de entrada de texto
`NubiTabs` -> Navegación entre subsecciones
`NubiStepper` -> Navegación entre pasos de un formulario
`NubiSpinner` -> Indicador de carga circular
`NubiSkeleton` -> Placeholder animado para contenido en carga
`NubiSidebar` -> Menú lateral de navegación
`NubiSessionIndicator` -> Indicador tiempo de sesión
`NubiSelect` -> Selector de opción única
`NubiRadioGroup` -> Grupo de radio buttons
`NubiProgressBar` -> Indicador de progreso
`NubiPinInput` -> Entrada de PIN de 4 dígitos
`NubiNumberInput` -> Entrada numérica
`NubiList` -> Lista de elementos apilados verticalmente
`NubiInfoModal` -> Modal informativo
`NubiInactivityOverlay` -> Overlay de inactividad
`NubiIconButton` -> Botón de acción con icono
`NubiIcon` -> Componente wrapper para iconos
`NubiGrid` -> Grid responsiba configurable
`NubiErrorState` -> Vista para errores 
`NubiEmptyState` -> Vista para cuando no hay datos
`NubiCounter` -> Muestra cantidades en modo estático o animado
`NubiConfirmModal` -> Dialogo de confirmación
`NubiCheckbox` -> Casilla de verificación
`NubiCard` -> Contenedor de contenido con estructura flexible
`NubiButton` -> Botón de acción
