# SKILL — agents-implementation

## Checklist
- Separacion de prompts, contexto, herramientas y datos.
- Agente infantil limitado al juego; chatbot adulto autenticado.
- Proteccion ante prompt injection y tool misuse.
- Salidas estructuradas y fallback seguro.
- No pedir datos personales ni dar consejo profesional.
- Casos de comportamiento, abuso, incertidumbre y regresion.
