# SKILL — infrastructure-review

## Cobertura especifica
- Validacion de Compose/configuracion y arranque limpio.
- Healthchecks, redes, puertos, volumenes y secretos.
- Recuperacion tras reinicio y persistencia esperada.
- Logs, observabilidad y limites de recursos.
- Rollback y procedimientos no destructivos.
- Smoke tests de conectividad entre servicios.
