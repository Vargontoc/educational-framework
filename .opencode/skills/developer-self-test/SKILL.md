# SKILL — developer-self-test

## Objetivo
Ejecutar comprobaciones antes de entregar el sprint al reviewer.

## Procedimiento
1. Identifica comandos oficiales del repositorio.
2. Ejecuta formato/lint, compilacion y pruebas de la capa.
3. Ejecuta pruebas nuevas y casos de error relevantes.
4. Registra comando, resultado, duracion aproximada y limitaciones.
5. Si falla algo, corrige o marca la tarea bloqueada; nunca ocultes el fallo.

## Resultado
Informe de autovalidacion. No equivale a aprobacion independiente.
