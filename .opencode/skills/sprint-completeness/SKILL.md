# SKILL — sprint-completeness

## Objetivo
Comprobar que el sprint implementa todo lo prometido.

## Procedimiento
1. Relaciona cada tarea con FEAT/ADR y criterios de aceptacion.
2. Verifica archivos, pruebas y evidencias declaradas.
3. Detecta tareas omitidas, parcialmente implementadas o fuera de alcance.
4. Comprueba documentacion y contratos requeridos.
5. Marca cada tarea `verified` o `rejected` con motivo.

## Regla
Un test verde no compensa una tarea ausente. La completitud se valida antes del cierre.
