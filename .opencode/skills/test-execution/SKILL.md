# SKILL — test-execution

## Objetivo
Ejecutar pruebas de forma reproducible y distinguir fallo de producto, entorno o prueba.

## Procedimiento
1. Descubre comandos oficiales y precondiciones.
2. Registra entorno y revision evaluada.
3. Ejecuta primero validaciones rapidas y luego suites relevantes.
4. Conserva salida suficiente para reproducir fallos.
5. Clasifica cada fallo: `product`, `test`, `environment`, `contract` o `unknown`.
6. No alteres codigo de produccion.

## Resultado
Tabla de comandos, estado, criterios cubiertos y evidencias.
