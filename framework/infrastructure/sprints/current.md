# Sprint 004 - infrastructure
# -----------------------------------------------

## Goal
Mount the eSpeak NG reference WAV files generated by the agents layer into the coqui-educational container per ADR-005, so XTTS v2 can use them for voice cloning.

## Status

waiting_for: framework/agents/tts/references/ directory populated with WAV files (calm.wav, joyful.wav, enthusiastic.wav, playful.wav, serious.wav)

## Tasks
- [ ] Add bind-mount `../agents/tts/references:/references:ro` to `coqui-educational` volumes in `docker-compose.yml`.
- [ ] Add same bind-mount to `coqui-educational` in `docker-compose.prod.yml`.
- [ ] Validate both compose stacks with `docker compose config`.

## Risks
- The bind-mount path `../agents/tts/references` is relative to the compose file location (`framework/infrastructure/`), resolving to `framework/agents/tts/references/`. If the directory does not exist at startup, Docker will create it empty and the container will start without reference files.
- The ADR snippet uses the old service name `educational-coqui` — correct name is `coqui-educational`.

## Dependencies
- Agents layer Sprint 008 must create `framework/agents/tts/references/` and populate it with the 5 WAV files before this mount is functional.
- This sprint can be committed before the WAV files exist (Docker will mount an empty directory without error), but voice cloning will fail at runtime until the agents layer delivers.

## Agent Instruction
- Only modify the `volumes` section of `coqui-educational` in `docker-compose.yml` and `docker-compose.prod.yml`.
- Path in compose must be `../agents/tts/references:/references:ro` — relative to `framework/infrastructure/`, resolving correctly to `framework/agents/tts/references/`.
- Do not change entrypoint, command, environment, ports, or any other field.
- After changes, validate: `docker compose config` and `docker compose -f docker-compose.yml -f docker-compose.prod.yml config`.

## Notes
Sprint triggered by ADR-005 (docs/architecture/decisions/ADR-005-Voice-Reference.md).
The `/references` mount point inside the container is consumed by the backend, which passes the WAV path as `speaker_wav` parameter in each XTTS v2 synthesis request.
ADR-005 status is `proposed` — confirm acceptance with human before merging this sprint branch.

## Acceptance Criteria
- `docker compose config` shows the bind-mount `../agents/tts/references` present in `coqui-educational` volumes.
- `docker compose -f docker-compose.yml -f docker-compose.prod.yml config` exits 0 and shows no published ports.
- Container starts without error even if `framework/agents/tts/references/` is empty.
