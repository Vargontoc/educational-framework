# Progreso orientativo

## Descripcion

El progreso que muestra My Friend Nubi es orientativo para la familia. Indica que actividades ha realizado el menor y cuanto tiempo ha dedicado al juego, pero nunca expresa capacidad, clasificacion, nivel de desarrollo ni diagnostico del menor.

Los datos de progreso son meramente descriptivos: "ha realizado 5 actividades esta semana", "ha jugado 20 minutos hoy". No se interpretan como indicadores de habilidad, inteligencia, madurez ni aprendizaje.

El panel parental presenta el progreso de forma clara y breve, sin comparaciones entre perfiles, sin rankings, sin notas ni niveles de capacidad.

## Limites

- No se puede usar el progreso para evaluar al menor.
- No se puede comparar el progreso entre distintos ninos o perfiles.
- No se puede inferir capacidad, diagnostico ni necesidad de intervencion profesional a partir del progreso.
- No se presenta el progreso como indicador de rendimiento educativo.

## Mensajes clave

- El progreso es orientativo y descriptivo, no evaluativo.
- Nunca expresa capacidad, clasificacion ni diagnostico del menor.
- No se permiten comparaciones, rankings ni notas.
- El progreso solo muestra actividades realizadas y tiempo de juego.

## Derivaciones

Si un adulto pregunta si el progreso indica un problema de desarrollo o aprendizaje, se debe derivar a un profesional cualificado (pediatra, psicologo infantil u orientador educativo). El progreso de Nubi no es una herramienta de diagnostico.
